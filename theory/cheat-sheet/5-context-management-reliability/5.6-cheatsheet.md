# Domain 5 · Task 5.6 — Preserve Information Provenance and Handle Uncertainty in Synthesis

**Exam objective**: When synthesizing multiple sources, keep an auditable claim→source trail, flag conflicts instead of silently resolving them, respect timestamps, and represent uncertainty honestly — so output is trustworthy and debuggable, not just coherent.

---

## Key concepts

- **Information provenance** — the documented origin of a claim. Every synthesized statement must trace to a specific source: document ID, URL, database row, or paragraph/character offset. No provenance ⇒ caller cannot verify, re-fetch, or audit.
- **Carry provenance from ingestion.** A retrieved chunk must never lose origin metadata as it flows through embedding → retrieval → synthesis. Once dropped, it cannot be reconstructed.
- **Claim-source mapping** — binds one discrete assertion to the source(s) supporting it. Minimum fields: claim text, source ID, location in source, retrieval timestamp. Richer: confidence score + verbatim excerpt.
- **Per-claim provenance, not per-response.** "The company was founded in 2012" is its own claim needing its own `sources` array. A single top-level citation list is insufficient.
- **Conflict annotation** — when sources disagree, surface both; do not pick a winner. Silent resolution = a form of hallucination (false certainty).
- **Temporal handling** — track `publishedAt` and `retrievedAt`; use timestamp distance as *one advisory signal*, never a deterministic override. Newer ≠ more authoritative.
- **Uncertainty in synthesis** — use a `confidence` (0.0–1.0 float, conventional) + a `reasoning` field explaining what lowered the score. Uncertainty *propagates*: conflicting sources → lower confidence than concordant sources, regardless of prose quality.

## Patterns & when to use them

**Preserving provenance / source attribution**
- Attach a `sources: SourceRef[]` array to *each* claim. `SourceRef` = `{ sourceId, location, excerpt, publishedAt, retrievedAt }`.
- Thread `sourceId`, `publishedAt`, `location` through every pipeline stage — do not strip metadata to save tokens.
- Schema shape (synthesis result): `{ summary, claims: SynthesizedClaim[], synthesizedAt }`, where `SynthesizedClaim = { claim, confidence, sources[], conflict, conflictSummary? }`.

**Handling uncertainty in synthesis**
- Emit a normalized `confidence`: ~0.9 = several independent sources agree; ~0.45 = evidence split; ~0.3 = weak/single.
- Never phrase a low-confidence claim as fact — either expose it via the `confidence` field or add hedging language in the claim text itself.
- Add a `reasoning` field describing why confidence dropped (conflict, single source, stale data).

**RAG grounding & citations**
- **Retrieval flow**: embed documents (`input_type="document"`) → embed query (`input_type="query"`) → nearest-neighbor / cosine similarity → retrieve top chunk(s) → synthesize *only* from retrieved context, citing each.
- Anthropic offers **no first-party embedding model**; docs point to **Voyage AI** (e.g. `voyage-4`, rerankers `rerank-2.5`). Embeddings are numeric vectors measuring semantic similarity.
- **Ground the answer in retrieved text and cite it** — the RAG analogue of provenance. Web search / server tools return **cited sources** automatically.
- Use **rerankers** to re-order candidates by relevance after initial vector retrieval.

**Conflicting sources handling**
- Detect during synthesis: compare excerpts; if they disagree, set `conflict: true` and populate `conflictSummary` (human-readable "[src A] '…' vs. [src B] '…'").
- Emit **both** claims with their respective source IDs. Do **not** average, do **not** auto-prefer recency, do **not** drop the minority claim.
- Timestamp comparison only *narrows* candidates; domain rules + confidence make the final call. Escalate the conflict to the caller.

**Prompting Claude to emit provenance-aware output**
- Use **tool use / structured output**: define an `emit_synthesis` tool whose `input_schema` requires `claim`, `confidence`, `sourceIds`, `conflict` per item; force it with `tool_choice: { type: "any" }`.
- Add `strict: true` to custom tool definitions to guarantee schema conformance.
- Instruct explicitly: "Flag any conflicts. Do not resolve conflicts."

## Gotchas / exam traps

- **Merging conflicting claims into one sentence** ("grew ~10–12%") hides disagreement. → Emit both values + `conflict: true`.
- **Dropping source metadata during retrieval/embedding** to save tokens — irreversible. → Carry `sourceId`, `publishedAt`, `location` end-to-end.
- **Treating recency as authority** — a 2019 peer-reviewed paper can beat yesterday's blog. Recency is *advisory only*.
- **Presenting low-confidence claims unqualified** — a 0.3 claim must not read as fact.
- **Omitting `conflictSummary` when `conflict === true`** — forces the caller to re-derive the disagreement.
- **One top-level citation for the whole response** — provenance must be **per-claim**.
- **Silent conflict resolution = hallucination** (false certainty) — the single most-tested principle here.
- **Auto-averaging numeric conflicts** is wrong — surface both, don't blend.

## Quick reference

| Concern | Do this | Don't |
|---|---|---|
| **Provenance tracking** | Carry `sourceId`, `location`, `excerpt`, `publishedAt`, `retrievedAt` from ingestion → synthesis | Strip metadata to save tokens |
| **Citation / attribution** | `sources[]` on *every claim* | Single response-level `[A,B,C]` list |
| **Uncertainty signaling** | `confidence` 0–1 + `reasoning`; hedge low scores | Present uncertain synthesis as definitive |
| **RAG retrieval + grounding** | Embed (Voyage) → similarity search → rerank → answer only from retrieved chunks, cite each | Answer from model memory ungrounded |
| **Conflicting sources** | `conflict: true` + `conflictSummary`; emit both claims w/ source IDs; escalate to caller | Average, auto-pick recent, or omit minority |
| **Temporal** | Track `publishedAt`/`retrievedAt`; recency = one advisory signal | Let newest source auto-win |

**Confidence heuristic:** 3 concordant sources ≈ 0.9 · split evidence ≈ 0.45 · single/weak ≈ 0.3.

**Core schema (memorize):**
```
SourceRef        = { sourceId, location, excerpt, publishedAt, retrievedAt }
SynthesizedClaim = { claim, confidence, sources[], conflict, conflictSummary? }
SynthesisResult  = { summary, claims[], synthesizedAt }
```

**One-liner:** *Trace every claim to its source, flag every conflict, hedge every uncertainty — silent resolution is hallucination.*
